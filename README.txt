PREVIEW
1. Extract the ZIP file to a folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. For the best local preview, install the VS Code extension "Live Server", right-click index.html, and choose "Open with Live Server".
   You can also double-click index.html to open it in a browser.

BEFORE PUBLISHING
1. Verify the WhatsApp number and email address are controlled by the business and monitored for enquiries.
2. Confirm the legal business name, experience statement and any qualifications, registrations or licenses before adding further claims.
3. Confirm which surveying and estate-development services are available directly and which, if any, are delivered by separate professionals or contractors. Agree responsibilities and scope in writing.
4. Confirm project-photo permissions and add client-approved project locations, scopes or outcomes only when verified. The current gallery captions describe visible field activity and do not claim client results.
5. Confirm all package inclusions, construction coordination availability, prices, timelines, warranties and exclusions before publishing any commitments.
6. Confirm the scope, suitability and delivery provider before making product or sanitation recommendations.
7. The enquiry form opens a prefilled WhatsApp message for the visitor to review and send. It does not submit data to a website server or store enquiries.
